5장 함수

1. 익명함수
	var functionVar = function() { }; // 함수 표현식
	var functionVar = () => {}; // 화살표 함수

2. 선언함수 
	function 함수명 ( ) { // 함수 선언식}
 		※  선언함수에서는 함수식 사용위치가 달라져도 항상 선언이 우선됨
		( 선언적 함수 정의 위에도 호출가능)

3. 디폴트값을 갖는 매개변수
	ex) function pow(x=5,y=2) 로 정의시 
		console.log(pow()) : 변수값 없이 입력해도 25로 출력됨
  		※ 단 python과 다르게 console.log(pow(y=2,x=3))  입력하더라도 x=2로 입력됨

4. 매개변수와 리턴값
	선언된 함수의 매개변수보다 많으면 뒷부분은 무시되고 
	작으면 전달되지 않은 매개변수에는 undefined 으로 출력됨
 
5. 가변인자함수
	매개변수의 갯수에 따라 변하는 함수. 화살표함수에서는 불가
	ex Array함수 경우 
		매개변수가 0개: length가 0인 배열을return
		매개변수가 1개: length가 매개변수만큼인 크기의 배열을 return 
		매개변수가 2개이상: 매개변수로 배열을 생성 return

6. 내부함수
	내부함수 : 함수내의 함수
			(함수내에서 호출하는 함수는 내부함수가 호출, 외부에서는사용불가)
	용도 : 같은 이름의 함수 정의 시 발생하는 충돌을 막기위함

7. 콜백함수
	매개변수에 넣어 전달된 함수

8. 내장함수(자바스크립트 내에서 호출 할 수 있는 함수)
   타이머함수
	setTimeout(function, millisecond) ; 일정시간 후 함수를 한번 실행
	setInterval(function, millisecond) ; 일정시간마다 함수를 반복해서 실행
	clearTimeout(id) ; setTimeout 중지
	clearInterval(id); setInterval 중지
