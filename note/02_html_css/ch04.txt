4장 CSS 선택자들
*선택자란 : 선택자란 웹페이지의 특정부분을 선택하여, 태그의 속성을 변경하는 목적으로 사용

1.태그선택자
 header, footer { border: 1px solid gray; 
     			text-align: cente}
	ex) border / text-align / margin / color 등 태그 속성을 변경할 수 있다.

2.전체(*) 선택자 ; 페이지 초기화
      margin: 0;
      padding: 0;

3.id(#)선택자 class(.)선택자
	태그의 id와 clas를 이용하여 CSS에 속성을 설정
    #wrap #content{width: 348px; 
        		height: 300px;}

4.혼합선택자
	tag, id, class를 혼합하여 CSS에서 속성을 설정
	div#header, div#footer { /*div태그중 id가 header이고 id가 footer}

5.속성 선택자
	선택자[속성] : 지정한 속성을 가지고 있는 요소를 찾아 스타일을 적용
	선택자[속성=값] : 속성 값이 특정값과 같은 경우를 찾아 스타일을 적용
	선택자[속성^=값] : 속성 값이 지정한 문자로 시작하는 속성값에 대해서만 스타일을 적용
	선택자[속성$=값] : 속성 값이 지정한 문자로 끝나는 속성에 대해서만 스타일을 적용


6.후손선택자, 자손선택자(바로아랫단)

7.동위(동생)선택자(+하나, ~다)

8.반응선택자(ex.마우스를 올릴때 반응)

9.상태선택자(ex. input에 focus된 상태)

10.구조선택자

11.문자/링크/부정선택자
