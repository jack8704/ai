3장 Form 공간분할
form태그 
	<form> : 사용자에게 입력 받는 공간
	<action> : 전달 위치를 지정
	<button> : 버튼을 생성
 	<checkbox> : 체크박스을 생성
	<file> : 파일 입력 양식을 생성
	<hidden> : 보이지 않게
	<image> : 이미지 형태를 생성
	<password> : 비밀번호 입력 양식을 생성
	<radio> : 라디오 버튼을 생성
	<reset> : 초기화 버튼을 생성
	<submit> : 제출 버튼을 생성
	<text> : 글자 입력 양식을 생성
