개요 및 주요 역할: 텍스트를 사람 목소리와 유사한 자연스러운 음성 오디오 데이터로 변환해 주는 OpenAI의 Text-to-Speech(TTS) API

환경 설정 및 인증: .env 파일에 OPENAI_API_KEY를 정의하고 python-dotenv 라이브러리로 불러와 OpenAI() 클라이언트 인스턴스 초기화

기본 호출 메서드 및 파라미터: client.audio.speech.create()를 호출하며, 기본 모델(model), 목소리 종류(voice), 변환할 텍스트(input)를 파라미터로 전달

모델 선택 (속도 vs 음질): 실시간 및 빠른 응답에 최적화된 기본 모델 tts-1과 연산량이 많아 음질 및 억양이 더 자연스러운 고품질 모델 tts-1-hd 제공

다양한 프리셋 목소리(Voice): alloy, echo, fable, nova, onyx, shimmer 등 고유 음색과 톤을 지닌 6가지 기본 프리셋 음성 지원

다국어 음성 지원: Whisper 모델의 언어 지원 체계를 기반으로 한국어, 스페인어 등 다국어 텍스트 지원 (자연스러운 억양 유도를 위해 문장부호 활용 가능)

발음 속도 조절 (speed): speed 파라미터를 통해 기본 배속(1.0) 기준 0.25배속에서 최대 4.0배속까지 음성 재생 속도 조절 가능

응답 데이터 포맷 (response_format): 기본 출력 포맷은 mp3이며, 필요에 따라 wav, aac, flac 등의 오디오 포맷으로 변경 지정 가능

오디오 파일 저장 방식: 반환된 바이너리(response.content)를 wb 모드로 직접 파일에 쓰거나, response.stream_to_file("경로") 편의 메서드를 사용해 저장

Jupyter 환경 내 재생: IPython.display.Audio(filename="...") 위젯을 사용하여 별도 오디오 플레이어 없이 노트북 셀 출력 화면에서 즉시 청취 및 재생 가능
